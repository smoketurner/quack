# Office Code Cross-Reference

A regional index lists office codes by state, unrelated to any single office page: AKQ,
CHS, ILM. Virginia's forecast office entries in the index name AKQ next to Wakefield,
Virginia. The index cites AKQ again for Wakefield, Virginia, and once more for a
retired Wakefield, Virginia listing. AKQ is confirmed a final time against Wakefield,
Virginia before the index closes.
